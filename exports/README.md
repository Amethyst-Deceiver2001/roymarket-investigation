# Registry exports

Generated by `python3 scripts/export_data.py` from `data/registry/`. Do not edit by hand; regenerate after a registry change. Nothing here is published: putting it on Pages or sending it to OpenSanctions, Aleph or anyone else is a separate decision.

| File | What it holds |
|---|---|
| `ftm/roymarket.ftm.json` | FollowTheMoney entities, one JSON object per line: `Company`, `Organization`, `PublicBody`, `Person`, `Ownership`, `Directorship`, `Family`, `UnknownLink`. Loads into OCCRP Aleph (`ftm` / `alephclient`) and the OpenSanctions tooling as is. |
| `csv/entities.csv` | One row per organisation: identifiers, registration date, address, ОКВЭД, tier, grade of the ЦБСТ tie, latest filed revenue, sanctions as the registry records them. |
| `csv/people.csv` | One row per person: ФИО, Latin form, birth date, birth place, personal ИНН. |
| `csv/ties.csv` | Every link in the network graph, with its evidence grade (documented / reported / not documented), date and source id. Includes products, programmes and events, which the FtM file leaves out. |
| `csv/sources.csv` | Every source a tie cites: plain-words title, public link where one exists, document date, SHA-256. |
| `manifest.json` | Run date, graph schema version, counts, whether PII is included, and the schema-validation result. |

**Scope.** The organisations and people the relationship graph admits: not adjacent or held-off entities, not reference-only people, not unresolved names.

**Left out on purpose.** Researcher notes and open questions; screening-tool output; people's home addresses, phones, e-mails and social handles. Sanctions are not FtM `Sanction` entities: the official lists are the authority, and many registry entries still rest on OpenSanctions. The CSV column is named so nobody mistakes it for a list extract. `--no-pii` also drops birth date, birth place and personal ИНН.

**Citing.** Entity ids are the registry's permanent slugs (`rm-<slug>` in FtM). Every FtM link carries its evidence grade and source title in `description`, the source's public link in `sourceUrl`, and the source id in `recordId`.

**Validation.** When the `followthemoney` package is installed (it needs the ICU library: `apt-get install libicu-dev pkg-config`, then `pip install followthemoney`), every entity is checked against the official schema, and any value the library's cleaning would drop is an error. `manifest.json` records whether this ran.
