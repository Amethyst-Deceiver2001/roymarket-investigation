# РОЙ.МАРКЕТ / ЦБСТ investigation

Corporate-genealogy OSINT investigation into ЦБСТ (Центр беспилотных систем
и технологий) and the РОЙ.МАРКЕТ "military marketplace" its subsidiary runs
— a companion piece to Alexey Kovalev's Foreign Policy article, and a
sanctions-lobbying reference document.

- **Read the brief**: `docs/index.html`, or the published Artifact
  (https://claude.ai/code/artifact/5450bf7e-7f7b-4788-93c0-761503dd5ea4 —
  may lag the local file, see `HANDOFF.md`).
- **New Claude Code session on this repo**: read `HANDOFF.md` first, then
  `CLAUDE.md` for working rules.
- **Migrated from** the `wb_watch` project on 2026-08-18.

## Layout

```
docs/index.html          the brief (GitHub Pages source once a remote exists)
docs/images/              evidence photos referenced by the brief
docs/_archive/            frozen snapshots of the brief, kept across restructures
data/sources/              primary-source EGRUL/БФО/press/court docs (gitignored, ~566MB)
data/sources/MANIFEST.md   filename -> ИНН/ОГРН/entities index, generated by scan_sources.py
data/registry/*.json       THE SOURCE OF TRUTH — entities/people/quotes/sources/open questions
data/registry/corrections.json   hand-made fixes with their reasoning; survive regeneration
data/roymarket.db         local Telegram-post DB (gitignored — own data, see below)
tg/                        own Telethon client/scraper/storage, independent of wb_watch
config/channels.txt        this investigation's own channel watchlist
.env                        TG_API_ID/TG_API_HASH/TG_SESSION (no .env.example template — holds real creds directly)
scripts/tg_login.py         one-time interactive Telegram auth
scripts/tg_scan.py          scrape config/channels.txt into data/roymarket.db (live network job — see CLAUDE.md)
scripts/mine_leads.py       entity/product/person extraction over data/roymarket.db (local, safe to rerun anytime)
scripts/id_patterns.py      shared extraction regex, used by mine_leads.py/extract_ids.py/scan_sources.py
scripts/extract_ids.py      general-purpose entity/ИНН/ОГРН scan over arbitrary pasted/fetched text
scripts/scan_sources.py     same extraction over every file in data/sources/, writes MANIFEST.md
scripts/har_tools.py        load_har() salvages truncated HAR captures (marketplace/site network traces)
scripts/screen_wb.py        joins registry ИНН against wb_watch's scraped WB sellers, writes wb_matches[]
scripts/reverse_source_index.py  derives entity/person <-> source citation map from sources.json's inns[], no duplicated storage
scripts/check_egrul_flags.py   flags EGRUL access-restriction/disavowal markers in pasted extract text
scripts/inventory_sources.py   reads data/sources/ once, caches doc type + as_of date (local, cached, rerun after new files)
scripts/extract_registry.py    one-time scaffold of data/registry/ from the frozen brief snapshot
scripts/check_registry.py      schema + ИНН/ОГРН checksums + duplicates; run before any build
scripts/check_tag_balance.py   run after every docs/index.html edit
scripts/export_from_wb_watch.py   historical bootstrap only, not the ongoing method
HANDOFF.md                full context for a new session — read this first
CLAUDE.md                 working rules
STYLE_GUIDE.md            voice + presentation rules — read before drafting prose
```
